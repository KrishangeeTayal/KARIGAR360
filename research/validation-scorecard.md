# Validation Scorecard

Use this scorecard after each field conversation. Do not fill it with assumed answers.

| Area | Evidence to capture | Notes |
|---|---|---|
| Current workflow | How jobs and material transfers are recorded | |
| Frequency | How often outsourced job-work occurs | |
| Pain point | Most difficult or error-prone step | |
| Consequence | Time, rework, delay or dispute impact described | |
| Existing tools | Registers, messaging, spreadsheets or software | |
| Shared acknowledgement | Whether both parties confirm transfers | |
| Reconciliation | How weights, purity and allowances are handled | |
| Karigar adoption | Access, trust, usability and incentive barriers | |
| Buyer | Who would approve adoption or payment | |
| Evidence | Anonymised example volunteered by participant | |

## Decision questions

- Did more than one jeweller independently describe a recurring problem?
- Is the problem consequential enough to justify a new workflow?
- Do karigars see value in participating?
- What existing practices or software already solve parts of the problem?
- What is the smallest workflow worth prototyping?

## Reporting rule

Separate direct observations, participant opinions, assumptions and proposed design decisions. Do not convert a small number of interviews into market-wide statistics.
