# Proposed User Workflows

## Workflow 1 — Create and issue a job

1. Jeweller creates a job.
2. Jeweller enters material details, weight, purity and agreed terms.
3. Jeweller assigns the karigar and expected completion date.
4. Material issue is recorded.
5. Karigar reviews and acknowledges receipt.

## Workflow 2 — Production updates

1. Karigar opens an assigned job.
2. Karigar records a progress update.
3. Supporting notes or evidence may be attached.
4. Both parties can view the updated job history.

## Workflow 3 — Returns

1. Karigar records a partial or final return.
2. Returned material details and relevant evidence are attached.
3. The job ledger records the return as a new event.
4. The remaining job balance/status is updated according to the agreed rules.

## Workflow 4 — Reconciliation and settlement

1. The system evaluates recorded material movements against the agreed reconciliation rules.
2. A proposed reconciliation is presented to both parties.
3. Either party may request clarification or dispute a difference.
4. Supporting evidence and corrections are added as traceable events.
5. Both parties review the final statement.
6. Settlement and closure require explicit approval.

## Event history principle

Corrections should not silently overwrite earlier records. A correction should be represented as a new event linked to the record it amends.
